Eyal Shtinmetz, Imree Cohen, Roni , Daneil Groshko, Renat Krimov, Guy Segal

Poject-Semster-2025-2026/

## Repository structure
- **client/** — user interface
- **server/** — backend services and APIs
- **common/** — shared code and utilities
-  **pom.xml /**          # Root Maven configuration
- **database/** — schemas, migrations, and data setup
- **lib/** — reusable libraries and helpers
- **README.md /**        # You are here!



## Quick start
```bash
# install deps
mvn install

# The server run on a cloud machine.
# The server should be running on a cloud machine 24/7
# At the IP 20.250.162.225:5555
# For any issues with the Backend server ask Eyal Shtinmetz
```
